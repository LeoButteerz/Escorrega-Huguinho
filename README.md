# Escorrega Huguinho
Joguinho estilo ice sliding puzzle para Unicap :)
Nesse jogo você controla Huguinho, que deve escorregar pela fase até chegar em seu grande amigo Oto!
---
O editor para montar as fases foi feito com ajuda do ComboBoy (https://comboboy.vercel.app)
O layout das fases foi inspirado por algumas fases desse site (https://icefloor.pages.dev)
